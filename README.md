# 東方忘却抄 ~ Oblivion Chronicle

> LLM-driven NPC agents in Gensokyo — layered memory, emotion state machines, and a deterministic world engine.

幻想乡的三个 NPC 由大模型驱动。她们记得你做过什么，会因此改变对你的态度，
并且能真的动手改变世界——收下你的东西、守住不该说的秘密、拒绝自己做不到的事。

## 无缘塚开满了会让人遗忘的花

线索分散在三个人手上，而她们都不会白给。灵梦要赛钱，魔理沙要交易，芙兰只要有人来看她。

下面是引擎侧的真实输出——面板、工具调用结果、失败原因。NPC 的台词由模型即时生成，这里不作预设：

```
── 第 0 回合 · 博丽神社 ──
幻想乡东端的神社。赛钱箱常年空着。
出口：人间之里、妖怪之山
身上：赛钱×8
在场：博丽灵梦（好感 0，烦躁度 0.10）
      平常的懒散语气
进展：你还没注意到幻想乡出了什么事

> 结界最近是不是出问题了
  ✗ 现在还不想告诉对方这件事——对方还没让你觉得值得说。

> /give 赛钱
在场：博丽灵梦（好感 6，烦躁度 0.00）

（……投到第四次……）

> 现在能说了吧
  ✓ 结界在三天前的子时出现了一次异常波动，方向正对无缘塚。
进展：关于那些花的线索正在陆续浮现
```

打错字、走不通、东西不在这儿，三种失败给的是三句不同的话，玩家不用猜：

```
/go 雾雨魔法店x  →  （幻想乡没有叫「雾雨魔法店x」的地方。）
/go 红魔馆地下室  →  （从博丽神社没法直接过去。）
/pick 赛钱       →  （这里没有赛钱。）
```

完整的对话录像见 `docs/screenshots/`（待补）。

**那次拒绝不是模型自己决定的。** `reveal_info` 这个动作在好感未达门槛时会被世界引擎直接判定失败，
而且门槛未满足时连 `fact_id` 都不会出现在她的 prompt 里——她连调用参数都凑不出来。
信息控制不依赖模型的自觉，而是物理上说不出来。

顺带一个细节：投赛钱让灵梦的**好感上升、烦躁度下降**。同一个动作在芙兰身上是兴奋度上升——
情绪增量按角色卡配置，同一事件在每个角色身上朝各自的方向走。

## 芙兰出不去

她被禁足在地下室，`move` 对她永久禁用。你让她出去看看，她拿到的失败原因是
「你被禁足在地下室里，出不去。」，这句话回灌进下一轮 prompt，于是她会改成请你代劳，
而不是反复尝试移动。**失败自愈在角色扮演里的形态不是重试，是换一个符合处境的做法。**

她的兴奋度超过 0.7 会进入 `destructive` 模式，此时 `available_tools()` 返回的列表真的不一样了——
解锁 `break_item`，同时禁掉 `ask_player`。LLM 看不到它不该有的工具，也就调不动。

## 三个 NPC，三种不同的难点

| NPC | 难点 | 机制 |
|---|---|---|
| 博丽灵梦 | 对抗助手腔——她该敷衍你的时候不能热心 | 角色卡禁语清单进系统提示 |
| 雾雨魔理沙 | 情报要换，不能白给 | 交易门槛在引擎里判定 |
| 芙兰朵露 | 情绪跃变会改变她能做什么 | 情绪状态机 gate 工具集 |

## 快速开始

```bash
git clone https://github.com/Rohawku/gensokyo-npc && cd gensokyo-npc
uv sync --extra dev
cp .env.example .env          # 指向你的 vLLM 或任意 OpenAI 兼容端点
make play
```

只想看世界引擎跑测试（**不需要模型、不需要网络、不到 1 秒**）：

```bash
make test
```

## 架构

```
cli  →  session  →  agent  →  llm
                      ↓
                    world      ← 零依赖，不含 LLM，不做网络 IO
```

`world/` 不 import 项目内任何其他模块。工具前置条件、任务状态机、态度与情绪计算全在这一层，
所以整个世界逻辑能在 1 秒内跑完全部单测，且回放完全确定——同一段动作日志两次重放必得同一状态
（用 Hypothesis 属性测试守着，三组各 50 个随机动作序列、合计 150 例无反例）。

存档存的是**动作日志**而非事件日志：事件 payload 里 `move` 的 `to` 是地点、`give_item` 的 `to`
是目标 NPC，同名不同义，从事件反推动作会猜错。动作日志只有一份真相，事件是它的推导产物。
